# WANI — Web Assembly Narrative Illustrator

Markdown からスライドを作り、ブラウザー内の Ruby でプレゼンテーションするツールです。
Rabbit へのオマージュとして、因幡の白兎に登場するワニ（鮫）にちなんだ名前です。

**Markdownを書いたら、あとは話す準備を。**

waniは、内容に合わせて文字サイズを自動調整するプレゼンテーションツールです。
タイトルも本文もスライドに収まる大きさに自動調整。
文字サイズの調整に手をかけず、伝えたい内容に集中してください。

兎とワニがスライドの進み具合を楽しく伝えます。
持ち時間も、発表の演出に。
最後の5秒は観客と一緒にカウントダウン。
時間になるとワニが登場し、発表のフィナーレを飾ります。

## インストールと開始

### インストール

[RubyGems.org](https://rubygems.org/gems/wani) からインストールできます。
Ruby 3.2 以上が必要です。

```sh
gem install wani
```

rbenv 環境でインストール後に `wani: command not found` となる場合は、
`rbenv rehash` を実行して実行ファイルの shim を更新してください。
ソースからのビルド手順は [開発・検証](docs/development.md) を参照してください。

### 開始

```sh
wani new my-talk
cd my-talk
wani check
wani serve
```


表示された http://127.0.0.1:8000/ をブラウザーで開きます。

`new`コマンドで生成されるプロジェクトには、Markdown記法を紹介する10ページの `slides.md` とサンプルSVG画像が含まれます。
`slides.md` を編集したらブラウザーを再読み込みしてください。

## Markdown記法

```markdown
---
time_limit: 5
---

# Ruby on WebAssembly

**Ruby** がブラウザーでスライドを描画します。

![構成図](images/architecture.svg)

<!--
notes:
ここで仕組みを説明します。
**ノートの Markdown** も使えます。
-->

---

## 次のスライド

見出しレベルが違っても、タイトルのデザインは同じです。
```

- 独立した `---` の行でスライドを分割
- 各ページの最初の見出しをタイトルに
- 本文には段落、強調、リスト、引用、コード、リンク、画像、表が使用可能
- コードフェンスに `ruby` や `js` などの言語名を付けると、スライド・ノート・PDFで構文ハイライトを適用
- 画像は、slides.mdを基準に相対パスで記述
- `<!-- notes: ... -->` は発表者ノート
- `<!-- page-footnote: ... -->` はページごとの脚注

詳細は [Markdown記法ガイド](docs/markdown.md) を参照してください。

## コマンド紹介

```sh
wani new DIRECTORY
```

`new`: サンプルを生成します。既存のディレクトリ、ファイル、シンボリックリンクは上書きしません。

```sh
wani check [FILE]
```

`check`: Front Matter・区切り・タイトル・ノート・画像を検証します。

- ファイル省略時は `slides.md`
- エラーは終了コード1、成功および警告のみの場合は0
- フォントのスライドからのはみ出しはブラウザーで表示するときに検出
- HTTP(S)画像も表示できますが、`check` の存在確認はローカル画像のみ


```sh
wani serve [FILE] --port 8000 --bind 127.0.0.1
```

`serve`: 指定ファイルを静的配信します。

- ファイル省略時は `slides.md`
- Ctrl+C で終了
- 初期バインド先は127.0.0.1。ポート 8000
- `--port` / `-p`、`--bind` / `-b` で変更
- ポート0を指定すると利用可能なポートを選択

```sh
wani --version
```

`version`: バージョンを表示します。

```sh
wani --help
```

`help`: ヘルプを表示します。


## 発表中の操作

| キー | 操作 |
| --- | --- |
| → / Space / PageDown | 次のスライド |
| ← / PageUp | 前のスライド |
| Home / End | 最初 / 最後 |
| F | 全画面の切り替え |
| Esc | 全画面を解除 |
| N | 発表者ノートを別ウィンドウに開く |


### ノート

- ノート画面はメイン画面の操作に同期
- 開けない場合はブラウザーのポップアップ設定を確認してください。

### 進捗表示

兎と鰐が進捗に連動します。

- 前半ではワニが右から左へ増えて橋を作る
- 後半では兎が左の島からサメの背中を通って右の島へ渡る
- ページを戻すと位置と橋も戻る
- 最終ページで兎が右端に到着

## 発表タイマー

hashなしのURLで開くと、最初のスライドに半透明の黒いベールと「スタート」ボタンを表示します。
待機中はページ移動と計測を止め、ボタンを押すとベールが消えてタイマーが始まります。Fキーで全画面にして待機できます。
`#slide=1` などのhash付きURLでは、読み込み完了から計測します。
既定では5分で時間切れ画面を表示します。
Front Matter の `time_limit` に分数を指定して変更できます（小数も可）。
`time_limit: 0` でタイマーを無効にします。

残り30秒になると、全画面表示中もカウントダウンを表示します。
残り5秒は中央に数字を表示し、画面の短辺に対して20％・40％・60％・80％・100％と強調サイズを増やします。
各数字は0.8秒で通常サイズに戻ります。動きを減らす設定では拡大アニメーションを省略します。
時間切れになると、兎柄フードをくわえたワニ（さめ）の画像を表示します。
画像は軽量なWebP形式で配布し、発表開始前に読み込みとデコードを済ませて、時間切れの文字と同時に表示します。
左右キーまたは「スライドに戻る」ボタンで、時間切れ直前のスライドに戻れます。
戻った後は通常通りページを移動でき、時間切れ画面は再表示しません。
最終スライドの表示中はタイマーを一時停止し、カウントダウンも時間切れ画面も表示しません。
前のスライドに戻ると、停止前の残り時間から再開します。1ページだけの場合も停止します。
ページを再読み込みするとタイマーも最初から始まります。
開始待ち画面、タイマー、時間切れ画面はPDFには含めません。

## スライド

- 1920×1080、16:9
- 白背景
- 画像は比率を維持して縦に配置し、画像だけの場合は本文領域を広く使います。
- `#slide=3` のようなハッシュ付き URL で特定のスライドを開く

### 画像とフォントを読み込み、幅と高さに合わせて文字サイズを自動調整
- タイトルは1行に収める
- 本文の段落・見出し・箇条書きは、使用フォントの全角20文字（「あ」20個）相当の幅以下なら折り返さず、それを超える場合は自然に折り返し
- 明示的な改行は維持。改行ごとに幅を判定
- 文字サイズは本文全体で共通


### 警告

- 収まらない内容に警告を表示
- 画像の読み込みを最大15秒待ち、失敗やタイムアウトを通知

## 印刷

ツールバーの「PDF」「ノート付き PDF」から印刷ダイアログを開き、PDFとして保存します。
Ctrl+P でも印刷できます。

- 用紙は320×180mmを指定し、ブラウザーのヘッダー・フッターはオフにしてください。
- 通常版は1スライド1ページ、ノート付きは各スライドの次に対応するノートを置きます。
- 画像・フォントの完了後に印刷し、ページごとの脚注とページ番号を出力します。兎と鰐の装飾は常に非表示です。


## 同梱フォント

日本語・英数字の標準書体は **IBM Plex Sans JP** です。
通常と太字のフォントを gem に同梱します。

本文・タイトル・発表者画面・PDF に同じ書体を使います。
コードには **UDEV Gothic** を使い、日本語も半角1:全角2の等幅で表示します。
UDEV Gothic も通常・太字を同梱するため、外部への通信やOSへのインストールは不要です。

フォントは SIL Open Font License 1.1 です。原文のライセンス・著作権表示と配布元・チェックサムは
[third_party/ibm-plex-sans-jp](third_party/ibm-plex-sans-jp/README.md) と
[third_party/udev-gothic](third_party/udev-gothic/README.md) に保持しています。

## フォントを変更する

タイトルと本文には、[Fontsource](https://fontsource.org/fonts)のフォントを追加して使えます。
フォントの追加時にはインターネット接続が必要です。追加後はオフラインで表示・PDF出力ができ、OSへのフォントのインストールやNode.js・npmは不要です。

### Fontsourceのフォントを使う

「Noto Sans JP」に変更する例です。

1. **フォントを選ぶ**

   [Fontsource](https://fontsource.org/fonts)で検索・プレビューし、使いたいフォントの名前を確認します。

2. **スライドのディレクトリで追加する**

   `slides.md`があるディレクトリへ移動して実行します。`my-talk`は自分のディレクトリ名に置き換えてください。既にその中にいる場合は`cd`は不要です。

   ```sh
   cd my-talk
   wani font add "Noto Sans JP"
   ```

   この操作で、そのプレゼンテーションにフォントをダウンロードします。Markdownの設定は次の手順で行います。

3. **`slides.md`の先頭に指定する**

   ```yaml
   ---
   font: Noto Sans JP
   ---
   ```

   既にFront Matter（先頭の`---`で囲んだ設定）がある場合は、その中に`font: Noto Sans JP`を追記します。
   設定の下に、スライドの見出しや本文を続けてください。コードの等幅フォントは変更されません。

4. **ブラウザーで確認する**

   ```sh
   wani serve slides.md
   ```

   表示されたURLをブラウザーで開きます。既に`wani serve`を起動している場合は、開いているページを再読み込みしてください。
   フォントが未登録・読み込み失敗の場合は警告を表示し、代替フォントで表示を続けます。

フォント名の代わりにIDやFontsourceの公式ページURLでも追加できます。例えば、手順2のコマンドを次のいずれかに置き換えられます。

```sh
wani font add noto-sans-jp
wani font add https://fontsource.org/fonts/noto-sans-jp
```

### 文字の太さを変える

Front Matterの`title-weight`でタイトル、`body-weight`で本文の太さを指定できます。

```yaml
---
font: Noto Sans JP
title-weight: 500
body-weight: 400
---
```

省略時はタイトル700・本文400です。`font`を省略して、既定フォントの太さだけを変えることもできます。
値の範囲やフォントによる表示の違いは [Markdown記法ガイド](docs/markdown.md#front-matter文書全体の設定) を参照してください。

### 追加済みフォントの確認・削除

`slides.md`があるディレクトリで、追加済みのフォントとIDを確認します。

```sh
wani font list
```

不要になったフォントは、一覧に表示されたIDを使って削除します。例えばNoto Sans JPなら次のとおりです。

```sh
wani font remove noto-sans-jp
```

スライドで使用中の場合は確認を求めます。削除する場合は、Front Matterの`font`も削除するか、別の追加済みフォントに変更してください。

### 他の人に渡す場合

追加したフォントは`fonts/ID/`、登録情報は`.wani/fonts.yml`に保存されます。
`slides.md`や画像と一緒に、`fonts/`と`.wani/fonts.yml`も保存・配布してください。`.wani`は隠しディレクトリなので、コピーし忘れないようにしてください。

各フォントのライセンスは`fonts/ID/LICENSE`に保存されます。Web公開・再配布・PDF配布の際は、そのフォントのライセンス条件を確認してください。

## 動作環境と制約

確認済みの環境は Linux / Ruby 4.0.7 / Chrome 156.0.8078.47 です。
Windows・WSL2、Edge / Firefox / Safari、通常ブラウザーの印刷ダイアログ操作は未検証です。

WSL2 内で `wani serve` を起動した場合は、Windows 側のブラウザーで http://localhost:8000/ を開きます。
環境のポート転送設定に応じて `--bind 0.0.0.0` を指定してください。

複雑に入れ子になった Markdown 方言、最適な画像の自動配置、ライブリロードは対象外です。
発表者画面はメイン画面の終了・再読み込み後に開き直してください。
