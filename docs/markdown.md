# Markdown記法ガイド

WANIの `slides.md` で利用できる記法を説明します。
使い始める手順は [README](../README.md) を参照してください。

WANIはkramdownのGFMパーサーを使い、対応する要素だけをHTMLに変換します。
GitHubで使えるすべてのMarkdown記法に対応するわけではありません。

## 文書全体の例

```markdown
---
time_limit: 5
---

# はじめての発表

**Ruby** とMarkdownでスライドを作ります。

- インストールする
- 原稿を書く
- ブラウザーで発表する

<!-- footer: 発表者名・イベント名 -->

<!-- notes:
最初に自己紹介します。
**強調**など、ノートでもMarkdownを使えます。
-->

---

# 構成図

![システムの構成](images/architecture.svg)
```

## Front Matter：文書全体の設定

ファイルの先頭に、`---` で囲んだYAMLを置けます。省略も可能です。

```yaml
---
time_limit: 5
---
```

| 設定 | 値 | 省略時 |
| --- | --- | --- |
| `time_limit` | 発表時間を分で指定。0以上の有限な数値 | `5` |

`time_limit: 2.5` のような小数も使えます。`time_limit: 0` でタイマーを無効にします。
文字列の `"5"`、負数、真偽値は指定できません。
タイマーの動作は [READMEの発表タイマー](../README.md#発表タイマー) を参照してください。

YAMLはマッピングで記述します。オブジェクト生成とaliasは許可しません。
閉じる `---` がない場合や、不正なYAMLはエラーです。
全ページ共通の `footer` と、装飾を切り替える `decorations` は使用しません。

## スライドの区切り

独立した `---` の行でページを分割します。前後を空行にすると読みやすくなります。

```markdown
# 最初のページ

本文です。

---

# 次のページ

次の本文です。
```

先頭の `---` はFront Matterの開始として扱います。
Front Matterを使わない場合は、見出しや本文から書き始めてください。
コードフェンス内、4スペース以上字下げしたコード内、コメント内の区切りでは分割しません。
区切りが連続するなどして空のスライドができた場合は警告します。

## タイトルと見出し

各ページの最初の見出しをタイトルに使い、本文から取り除きます。
`#` から `######` まで、どのレベルでもタイトルのデザインは同じです。

```markdown
# このページのタイトル

本文です。
```

タイトル内の強調やリンクなどはプレーンテキストになります。
同じページに2つ目以降の見出しがある場合は、本文に見出しとして残して警告します。
タイトルなしのページも使えますが、`#` だけの空タイトルはエラーです。

## 段落と改行

空行で段落を分けます。明示的に改行する場合は、行末に半角スペースを2つ置きます。

```markdown
最初の段落です。

次の段落です。
```

Markdownの記号自体を表示するときは、`\*` のようにバックスラッシュでエスケープするか、
インラインコードを使います。

## 強調と取り消し線

```markdown
*強調* または _強調_

**太字** または __太字__

~~取り消し線~~
```

## リスト

箇条書きと番号付きリストを使えます。

```markdown
- 準備する
- 原稿を書く
- 発表する

1. サーバーを起動する
2. ブラウザーを開く
3. スライドを進める
```

リストの入れ子は字下げして記述します。複雑な入れ子は動作保証の対象外です。
番号の開始値など、任意のHTML属性は表示に引き継ぎません。

## 引用

```markdown
> 引用する文章です。
>
> 段落を分けることもできます。
```

## コード

文中のコードはバッククォートで囲みます。

```markdown
`puts "Hello"` を実行します。
```

複数行はバッククォート3つ以上、またはチルダ3つ以上のフェンスで囲みます。

````markdown
```ruby
puts "Hello, Wani!"
```
````

フェンスは0〜3スペースの字下げに対応します。4スペース以上の字下げでもコードを記述できます。
言語名を書いても構文ハイライトは行いません。
閉じていないコードフェンスは警告します。
コード内の `---` や `<!-- footer: ... -->` は、区切りや設定として扱いません。

## リンク

```markdown
[Rubyのサイト](https://www.ruby-lang.org/ja/)

[メールを送る](mailto:speaker@example.com)

[関連資料](handout.pdf)
```

HTTP、HTTPS、mailtoのURLと相対パスを使えます。
相対パスは、スライドのMarkdownファイルがある場所を基準に解決します。
`javascript:` などの危険なURLは除去して警告します。
`//example.com` のようなプロトコル省略URLも使用できません。
空白を含むパスは `handout%20notes.pdf` のようにURLエンコードしてください。

## 画像

```markdown
![構成図の説明](images/architecture.svg)

![写真](images/photo.jpg)
```

PNG、JPEG、WebP、SVGに対応します。HTTP(S)の画像URLも使えます。
相対パスの基準はMarkdownファイルの場所です。
`wani check` はローカル画像の存在を確認しますが、外部URLの画像は確認しません。
`data:` URLや任意のHTML属性によるサイズ指定は使用できません。

画像は縦横比を維持して縦に配置します。画像だけのページは本文領域を広く使います。
画像の読み込みに失敗した場合や、読み込みがタイムアウトした場合はブラウザーで通知します。

## 表

```markdown
| 操作 | キー |
| --- | --- |
| 次のページ | → |
| 前のページ | ← |
| 発表者ノート | N |
```

表の見出しとセルを表示します。配置指定などのHTML属性は引き継ぎません。
大きな表はページに収まらないことがあるため、複数ページへの分割を検討してください。

## 発表者ノート

ページ内の `notes:` コメントに、発表中に参照する文章を書きます。

```markdown
<!-- notes:
ここでデモに切り替えます。

- 操作を見せる
- 結果を説明する
-->
```

ノートは通常のスライド本文には表示せず、発表者画面とノート付きPDFに表示します。
本文と同じMarkdown記法を使えます。
複数のノートブロックは警告して結合します。閉じていないコメントはエラーです。

## ページごとのフッター

```markdown
<!-- footer: 発表者名・イベント名 -->
```

指定したページだけに表示します。省略時や `<!-- footer: -->` を指定した場合は空になります。
複数の指定があれば警告し、最後の値を採用します。
フッターはプレーンテキストで、強調やHTMLの装飾は適用しません。
発表者画面とノート付きPDFにも同じ値を表示します。

ページ番号はフッターと別に自動表示します。
`1/10` の形式で現在ページと全スライド数を示し、ノート付きPDFでも元のスライド番号を使います。

## 対応範囲と確認方法

任意のHTMLや属性は引き継がず、対応するMarkdown要素だけを表示します。
HTMLによる装飾、スクリプト、iframeの埋め込み、構文ハイライトには対応しません。
脚注など、GFMやkramdownのすべての拡張記法に対応するものではありません。
ページごとのフッターは、本文に参照番号を付けるMarkdownの脚注とは別の機能です。

`wani check slides.md` で構文やローカル画像を確認した後、ブラウザーで表示を確認してください。
実際のはみ出しはブラウザーが検出します。収まらない内容は自動でページ分割せず、警告します。
印刷方法は [READMEの発表と印刷](../README.md#発表と印刷) を参照してください。
通常のPDF・ノート付きPDFとも、兎と鰐の装飾は常に非表示です。
